# 图像基础面试复盘

> 记忆主线：传感器采集 **RAW（如 RGGB）** → **ISP** 处理 → 输出 RGB 或 YCbCr → 显示、编码或交给视觉算法。HDR 可以涉及采集、多帧融合和后续色调映射等多个环节。

# YUV

## YUV的定义

YUV 的核心思想是把图像的**明暗信息和颜色信息分开表示**：

- **Y：亮度相关分量**，可以近似理解为去掉颜色后的灰度图。
- **U、V：色度分量**，描述颜色相对于亮度的差异，分别与蓝色色差、红色色差有关。

**为什么要分开？** 人眼通常对明暗细节更敏感，对颜色细节相对不敏感。因此可以保留更多亮度细节，减少颜色数据，节省带宽和存储。

> **面试表述：** YUV 是一种亮度和色度分离的表示方式，方便对色度降采样，常用于视频采集、传输和编码。工程里说的“YUV”通常实际指数字视频中的 **YCbCr**；严格来说，YUV 和 YCbCr 并不完全相同。

## RGB和YUV的转换

**核心原理：加权求亮度，再计算色差。** 下面以常见的 **BT.601、8 bit 全范围 YCbCr** 为例：

```text
Y  =  0.299 R + 0.587 G + 0.114 B
Cb = -0.168736 R - 0.331264 G + 0.5 B + 128
Cr =  0.5 R - 0.418688 G - 0.081312 B + 128
```

- R、G、B 取值为 0～255；这里更严格地说，是经过非线性编码的 R′、G′、B′。
- 绿色的权重最大，符合人眼对不同颜色的亮度敏感程度。
- Cb、Cr 加 128，是把有正有负的色差信号平移到无符号数范围；中性灰的 Cb、Cr 约为 128。

对应的反向转换为：

```text
R = Y + 1.402 (Cr - 128)
G = Y - 0.344136 (Cb - 128) - 0.714136 (Cr - 128)
B = Y + 1.772 (Cb - 128)
```

实际实现需要取整，并把越界结果裁剪到合法范围。

**面试重点不是背全系数，而是理解转换条件：**

- **标准不同，系数不同**，例如 BT.601 和 BT.709。
- **全范围与有限范围不同**：常见 8 bit 有限范围的 Y 为 16～235，Cb、Cr 为 16～240，不能直接套用上面的全范围公式。
- **颜色转换和色度降采样是两件事**：RGB 转 YCbCr 本身不必减少采样点；转成 4:2:0 时才会进一步减少色度采样。

> **常见追问：转换后为什么偏色或发灰？** 优先检查转换矩阵、全范围/有限范围、UV 顺序和内存布局是否匹配。

## YUV的优势和劣势

| 方面 | 面试重点 |
| --- | --- |
| 优势：便于压缩 | 可利用人眼特性对色度降采样，在较小感知损失下减少数据量。 |
| 优势：适合视频链路 | 摄像头、编解码器常支持 YCbCr，便于视频处理和传输。 |
| 优势：可单独处理亮度 | 某些灰度分析可以直接使用 Y，避免先转 RGB。 |
| 劣势：色度细节损失 | 4:2:0 等降采样格式可能使彩色细线、文字边缘出现模糊或渗色。 |
| 劣势：格式容易混淆 | 标准、取值范围、平面布局、UV 顺序不匹配，都可能造成显示异常。 |
| 劣势：部分算法需转换 | 许多显示或视觉模型接口使用 RGB，需要额外转换。 |

**注意：YUV 不等于有损压缩。** 理想的可逆颜色变换不必丢失信息；实际整数转换会有量化误差，色度降采样通常会丢失颜色细节。

## YUV420的定义和核心优势

**4:2:0 表示色度采样密度：每个 2×2 的亮度块，有 4 个 Y 样本、1 个 Cb 样本和 1 个 Cr 样本。** 色度在水平和垂直方向的分辨率都减半。

```text
2×2 像素区域：
Y00  Y01     对应 1 个 Cb、1 个 Cr 样本
Y10  Y11
```

这里表示采样数量，具体色度采样位置取决于格式约定，不能简单理解成只取左上角像素的颜色。

**数据量计算（8 bit、宽高为偶数、无额外行对齐）：**

```text
Y：W × H 字节
Cb：W × H / 4 字节
Cr：W × H / 4 字节
合计：W × H × 1.5 字节，即平均 12 bit/像素

RGB888：W × H × 3 字节，即 24 bit/像素
```

因此，YUV420 的裸数据量约为 RGB888 的一半。**这是采样格式带来的节省，不是 H.264/H.265 编码后的压缩率。**

常见内存布局：

| 格式 | 存储顺序 | 区别 |
| --- | --- | --- |
| I420 | Y 平面 → U 平面 → V 平面 | 三个独立平面 |
| YV12 | Y 平面 → V 平面 → U 平面 | 与 I420 的 U、V 顺序相反 |
| NV12 | Y 平面 → UVUV… | 色度交错存储 |
| NV21 | Y 平面 → VUVU… | 与 NV12 的 U、V 顺序相反 |

> **面试表述：** YUV420 保留完整的亮度分辨率，把两个色度分量在水平、垂直方向各减半。8 bit 下平均每像素 12 bit，比 RGB888 减少一半裸数据量，是画质和带宽之间常见的折中。

# RGGB格式

## RGGB的定义

**RGGB 是一种 Bayer 彩色滤光阵列排列方式，常见于传感器输出的 RAW 数据。** 一个重复的 2×2 单元为：

```text
R G
G B
```

- 每个感光位置通常只测得 **R、G、B 中的一种颜色**，并没有完整的三个通道。
- 绿色采样点占一半，红色、蓝色各占四分之一，有利于保留亮度和空间细节。
- 常见 Bayer 排列还有 BGGR、GRBG、GBRG，解码时必须匹配。
- RAW 常见位深有 10 bit、12 bit、14 bit；**RGGB 描述颜色排列，不代表位深或字节打包方式**。

> **面试表述：** RGGB 是 Bayer RAW 的一种排列，每个像素只采一种颜色，需要通过去马赛克重建完整 RGB。它和每像素都有三个通道的 RGB 图像不同。

## RGGB到正常图像的转换

关键步骤是 **去马赛克（Demosaicing，也叫解拜耳）**：根据周围采样值，估计每个位置缺失的两个颜色分量。

例如在一个 R 采样点上：R 来自测量，G 可以根据上下左右的 G 估计，B 可以根据对角线的 B 估计。这是简单插值思路；更好的算法会考虑边缘方向，减少跨边缘插值。

**但去马赛克并不等于完成全部成像处理。** 一条简化的处理链路是：

```text
RAW
 → 黑电平校正、坏点校正等
 → 白平衡增益、RAW 域降噪等
 → 去马赛克，得到完整 RGB
 → 颜色校正、色调/Gamma 处理等
 → 可显示图像或 YCbCr 输出
```

实际 ISP 的顺序可能不同，部分模块也会分布在多个阶段。

**常见追问：**

- **为什么直接显示 RAW 会偏暗、偏绿？** RAW 尚未经过完整的白平衡、颜色和显示编码处理；Bayer 采样中绿色点也更多，直接当普通图像解释会出现异常。
- **去马赛克有什么问题？** 在细密纹理和边缘处可能出现伪色、摩尔纹、锯齿，根本原因是缺失颜色需要估计，而采样信息有限。
- **RGGB 顺序弄错会怎样？** 颜色异常；例如红蓝颠倒。裁剪起点改变或翻转图像后，也要检查 Bayer 排列是否变化。

# Gamma 矫正算法


## 定义

**Gamma 校正是一种非线性灰度映射，用幂函数改变不同亮度区间的数值分布。**

先把输入归一化到 0～1，以如下约定为例：

```text
y = x^γ
```

- **γ < 1：** 中间灰度变亮，暗部被抬升。
- **γ > 1：** 中间灰度变暗。
- **γ = 1：** 不变。

例如 x = 0.25，γ = 0.5 时，y = 0.5，灰度被抬高。

**面试易错点：** 有些资料写成 `y = x^(1/γ)`，此时参数方向相反。回答“Gamma 大于 1 会变亮还是变暗”之前，先明确公式。

## 核心作用

1. **匹配显示链路。** 线性光信号与显示设备的响应并不直接一致，需要相应的编码与解码，才能正确还原明暗。
2. **提高有限位深的利用效率。** 人眼对暗部的相对变化更敏感，非线性编码可以给暗部更多码值，减少可见量化问题。
3. **调整图像明暗。** 幂函数映射也可用于抬升暗部或压暗中间调，但这属于图像调整用途，要和标准显示编码区分。

**与线性调亮的区别：** 乘一个增益会按比例放大所有数值，容易使高光截断；Gamma 会非线性改变中间调，在上述归一化公式下保持 0 和 1 不变。

**两个高频追问：**

- **sRGB 就是简单的 2.2 次幂吗？** 不是。sRGB 使用分段传递函数，暗部有线性段；2.2 只是常见近似说法。
- **Gamma 能恢复过曝细节吗？** 不能。如果采集时高光已经饱和，或量化时细节已丢失，调整 Gamma 无法把真实细节找回来。

> **面试表述：** Gamma 校正通过非线性映射处理亮度，主要服务于显示响应匹配和感知编码，也可用来调整中间调。要先说清公式，避免把参数方向答反。

# HDR图像

## 定义

**HDR（High Dynamic Range，高动态范围）指能够表示或保留更大亮暗范围的图像。** 动态范围可以直观理解为：系统能同时区分的最亮信号与最暗有效信号之间的跨度。

典型场景是室内拍窗外：室内很暗、窗外很亮。普通曝光可能只能保住一边，另一边要么过暗，要么过曝。

**常见实现方式：**

- **多曝光融合：** 短曝光保留高光，长曝光保留暗部，经过对齐和融合得到更大动态范围的结果。
- **传感器级 HDR：** 通过多增益、多曝光读出等方式获取更大范围的信息，具体方式取决于传感器设计。

**HDR 到普通屏幕显示，还需要色调映射（Tone Mapping）：** 把较大的亮度范围压缩到屏幕能显示的范围，同时尽量保留局部细节和自然观感。

**面试常见追问：**

| 问题 | 重点回答 |
| --- | --- |
| HDR 和高分辨率有什么区别？ | HDR 解决亮暗范围，分辨率解决空间细节，两个概念独立。 |
| HDR 等于高位深吗？ | 不等于。高位深提供更多量化等级，有助于表示 HDR，但不能单独证明采集到了更大的动态范围。 |
| 多帧 HDR 有什么难点？ | 物体或相机运动可能导致重影；还需要解决对齐、噪声、曝光差异和融合过渡。 |
| 色调映射有什么问题？ | 处理过强可能出现光晕、局部对比度异常或画面不自然。 |
| HDR 就是把暗处提亮吗？ | 不是。核心是获取或保留更大的亮暗范围，单纯提亮不能恢复已丢失的信息。 |

> **面试表述：** HDR 的目标是在大光比场景下同时保留亮部和暗部细节，常用多曝光融合或传感器级方案实现。多帧融合要重点处理运动重影，输出到普通显示设备时通常还需要色调映射。

# ISP 图像信号处理器

## 定义与作用

**ISP（Image Signal Processor，图像信号处理器）负责把传感器采集的原始数据，处理成适合观看、编码或算法使用的图像。**

可以把传感器理解为“采集原材料”，ISP 则负责“校准、补全、降噪和调色”。RAW 只是相对原始的测量数据，并不是直接可用的照片。

## 核心处理模块

| 模块 | 做什么 | 主要解决的问题 |
| --- | --- | --- |
| 黑电平校正（BLC） | 扣除传感器的黑电平偏置 | 无光时读数也可能不为零，影响暗部和颜色 |
| 坏点校正（DPC） | 用邻域信息修正异常像素 | 固定亮点、暗点 |
| 镜头阴影校正（LSC） | 补偿画面位置相关的亮度、颜色衰减 | 四角偏暗、颜色不均 |
| 白平衡（AWB） | 估计光源并调整各颜色通道增益 | 白色物体在不同光源下产生色偏 |
| 降噪（NR） | 抑制空间或时间上的噪声 | 暗光颗粒、彩噪；过强会丢纹理 |
| 去马赛克 | 从 Bayer 数据重建完整 RGB | 每个位置缺少两个颜色分量 |
| 颜色校正（CCM） | 通常用矩阵校正传感器颜色响应 | 颜色不准确；与白平衡作用不同 |
| 色调映射与 Gamma | 调整亮度范围并匹配显示编码 | 大光比显示、明暗呈现 |
| 锐化 | 增强边缘和细节观感 | 画面偏软；过强会出现白边或放大噪声 |
| 颜色空间转换 | 如 RGB 转 YCbCr | 适配编码、传输和下游接口 |

这是一组常见模块，**不是所有 ISP 都严格按表格顺序执行**。降噪等处理可能在 RAW、RGB、YCbCr 多个域中进行。

## 3A：面试常问的自动控制

- **AE（自动曝光）：** 根据场景调整曝光时间、增益，部分设备还可调整光圈，让画面曝光合适。长曝光可能增加运动模糊，高增益会放大已有噪声。
- **AWB（自动白平衡）：** 估计光源色温等特性，调整通道增益，让中性色尽量保持中性。
- **AF（自动对焦）：** 控制镜头位置，使目标成像清晰。

3A 通常结合图像统计、控制算法以及传感器/镜头执行机构形成反馈闭环，并不都是对像素做一次变换。

## 面试回答与排查思路

> **面试表述：** ISP 把 RAW 转成可用图像，核心包括黑电平、坏点、镜头阴影、白平衡、降噪、去马赛克、颜色校正、Gamma 和锐化等处理，并配合 AE、AWB、AF 完成自动成像控制。调优时需要平衡噪声、细节、色彩、动态范围和实时性。

遇到画质问题，可以先按现象定位：

- **整体偏色：** 检查 Bayer 排列、白平衡、颜色校正，以及 YCbCr 转换标准和 UV 顺序。
- **暗处噪声大：** 检查曝光、增益和降噪；降噪过强又可能产生“涂抹感”。
- **细密纹理出现彩纹：** 考虑采样混叠、去马赛克引入的伪色或摩尔纹。
- **运动物体拖影：** 区分长曝光导致的运动模糊、多帧降噪导致的拖影，以及 HDR 融合重影。
- **边缘有明显白边：** 检查锐化是否过强。

# 面试前一分钟速记

- **YUV/YCbCr：** 亮度、色度分离，便于减少色度数据；标准、范围和布局要匹配。
- **YUV420：** 2×2 区域为 4Y + 1U + 1V，8 bit 下平均 12 bit/像素。
- **RGGB：** Bayer RAW 排列，每个位置只有一种颜色；去马赛克补全另外两种颜色。
- **Gamma：** 非线性亮度映射；先明确指数公式，再判断变亮还是变暗。
- **HDR：** 保留更大的亮暗范围，关注多曝光融合、运动重影和色调映射。
- **ISP：** 把 RAW 加工为可用图像；画质调优本质上需要在多项目标间做权衡。
