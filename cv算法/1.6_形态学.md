## 一、形态学解决什么问题？

数学形态学通过**结构元素（Structuring Element）**在图像上滑动，对目标的**形状、大小、连接关系**进行处理。

在二值图中，通常约定：

- **白色（255）是前景**：需要分析的目标、缺陷区域。
- **黑色（0）是背景**。

> ⚠️ 所有“扩大目标”“去除白色噪点”等表述均基于**白色代表前景**。如果缺陷是黑色的，需要先明确前景定义，必要时反转二值图。

形态学通常位于传统视觉处理流水线的**阈值分割之后、连通域分析之前**：

```text
原图 → 灰度化 → 滤波 → 阈值分割 → 形态学 → 连通域 → 缺陷面积/位置/尺寸
```

## 二、四个核心操作（必须掌握）

| 操作 | 英文 / OpenCV | 核心变化 | 常见用途 | 主要风险 |
|---|---|---|---|---|
| 腐蚀 | Erosion / `cv2.erode` | 白色前景收缩 | 去细小突起、分离细连接 | 细小真实缺陷可能消失 |
| 膨胀 | Dilation / `cv2.dilate` | 白色前景扩张 | 连接近邻区域、加粗线条 | 相邻独立缺陷可能粘连 |
| 开运算 | Opening / `cv2.MORPH_OPEN` | **先腐蚀，后膨胀** | 去除孤立白色小噪点、细突出 | 小型真实前景也会被去掉 |
| 闭运算 | Closing / `cv2.MORPH_CLOSE` | **先膨胀，后腐蚀** | 填补白色目标内的小黑孔、连接窄缝 | 不同目标可能被误连接 |

**记忆法**：

- 腐蚀：白色**变小**。
- 膨胀：白色**变大**。
- 开：**先缩后扩**，消除小的白色结构。
- 闭：**先扩后缩**，修补小的黑色空隙。

### 2.1 腐蚀（Erosion）

**直觉**：把结构元素放在每一个候选位置，**只有结构元素覆盖的前景位置全部满足前景条件，该位置才保留为前景**。

对于二值集合 $A$（前景像素坐标的集合）和结构元素 $B$：

$$
A\ominus B=\{x\mid B_x\subseteq A\}
$$

其中 $B_x$ 表示把结构元素 $B$ 平移到位置 $x$。

对**平坦结构元素**的灰度图，腐蚀相当于局部取最小值：

$$
(I\ominus B)(x)=\min_{b\in B}I(x+b)
$$

```python
result = cv2.erode(binary, kernel, iterations=1)
```

**何时使用**：二值分割后出现局部毛刺或细连接时。注意腐蚀会让真实目标面积变小，不能默认用于精确尺寸测量的最终掩码。

### 2.2 膨胀（Dilation）

**直觉**：结构元素覆盖的区域中，**只要存在前景像素，就能使对应输出位置成为前景**（对常见对称核而言）。

二值集合定义为：

$$
A\oplus B=\{a+b\mid a\in A,\ b\in B\}
$$

对平坦结构元素的灰度图，膨胀相当于局部取最大值（此处以对称核书写）：

$$
(I\oplus B)(x)=\max_{b\in B}I(x+b)
$$

```python
result = cv2.dilate(binary, kernel, iterations=1)
```

**何时使用**：让断开的细线靠近、增强较细的前景区域。膨胀会增大测得面积，也可能把两个本应独立的缺陷合并。

### 2.3 开运算（Opening）

顺序极重要：**先腐蚀，再膨胀**。

$$
A\circ B=(A\ominus B)\oplus B
$$

```python
result = cv2.morphologyEx(binary, cv2.MORPH_OPEN, kernel)
```

**为什么能去小白点？** 小于结构元素所能容纳尺度的孤立白色区域，往往在腐蚀阶段被完全删除，后续膨胀无法让它凭空恢复；较大的区域可在一定程度上恢复外形。

**注意**：“开运算后原图不变”不成立，边界、角点和细长结构可能改变。

### 2.4 闭运算（Closing）

顺序极重要：**先膨胀，再腐蚀**。

$$
A\bullet B=(A\oplus B)\ominus B
$$

```python
result = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)
```

**为什么能填小黑洞？** 膨胀先从白色目标边缘向孔洞或窄缝延伸，使小空隙被覆盖；后续腐蚀将外边界适度收回，但已经被消除的细小孔洞可能不再出现。

**注意**：闭运算适于填补与结构元素尺度相匹配的小孔洞或窄缝，不代表能够可靠填满任意大小、任意形状的孔洞。

## 三、结构元素 Kernel：决定操作效果的关键参数

结构元素是一个小的形状模板，决定“检查哪一片邻域”。主要由**形状、大小、锚点（anchor）**决定。

OpenCV 常用类型：

```python
import cv2

rect = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))
ellipse = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))
cross = cv2.getStructuringElement(cv2.MORPH_CROSS, (3, 3))
```

| 结构元素 | 特点 | 可尝试的情形 |
|---|---|---|
| 矩形 `MORPH_RECT` | 覆盖邻域较充分，易改变直角/边缘 | 常规二值掩码处理 |
| 椭圆 `MORPH_ELLIPSE` | 更接近各方向均匀的作用 | 圆斑、一般颗粒缺陷 |
| 十字 `MORPH_CROSS` | 更突出水平/垂直邻接关系 | 细线、特定连通结构 |

**大小如何选？**

- 从 `3×3` 开始，逐步比较 `5×5`、`7×7`。
- 核过小，噪点可能清理不干净；核过大，真实微小缺陷也会消失或相邻缺陷合并。
- 工业视觉中应参考**像素分辨率、最小目标尺寸、缺陷方向**选核，而不是只凭肉眼选一个参数。
- 对有方向性的细长划痕，可以额外试验 `1×k`、`k×1` 的方向性结构元素。

**迭代次数 `iterations`**：重复操作会增强作用，但一般不等价于任意情况下简单地使用更大的结构元素。必须在具体操作、形状和边界条件下比较。

## 四、形态学与滤波、阈值分割的关系

| 方法 | 处理重点 | 常见输入 | 主要用途 |
|---|---|---|---|
| 均值/高斯/中值滤波 | 像素值与噪声 | 灰度或彩色图 | 减少噪声、平滑 |
| 阈值分割 | 像素归属前景还是背景 | 灰度图 | 生成二值掩码 |
| 数学形态学 | 前景形状与局部几何 | 多为二值掩码，也可为灰度图 | 去碎点、接断裂、补孔、修边 |
| 连通域分析 | 对独立前景区域编号和统计 | 二值掩码 | 面积、质心、外接框、数量 |

**关键理解**：形态学不是神经网络中的卷积，也不是简单平均。它主要基于集合运算，或对灰度邻域进行 `min/max` 操作。

## 五、OpenCV 完整练习代码

下面的代码直接构造包含**目标、小白点、内部黑孔**的二值图，不依赖外部图片。运行后会在当前目录生成 5 张图像，方便对比。

```python
import cv2
import numpy as np

# 1. 构造 0/255 二值测试图
binary = np.zeros((160, 240), dtype=np.uint8)
cv2.rectangle(binary, (55, 35), (185, 125), 255, thickness=-1)
cv2.circle(binary, (120, 80), 4, 0, thickness=-1)  # 目标内部黑孔
binary[10:13, 12:15] = 255                          # 孤立白点
binary[140:143, 215:218] = 255                      # 孤立白点

# 2. 核
kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))

# 3. 四种形态学操作
eroded = cv2.erode(binary, kernel, iterations=1)
dilated = cv2.dilate(binary, kernel, iterations=1)
opened = cv2.morphologyEx(binary, cv2.MORPH_OPEN, kernel)
closed = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)

# 4. 保存对比结果
results = {
    '00_original.png': binary,
    '01_eroded.png': eroded,
    '02_dilated.png': dilated,
    '03_opened.png': opened,
    '04_closed.png': closed,
}
for filename, img in results.items():
    cv2.imwrite(filename, img)
    print(filename, 'white pixels:', cv2.countNonZero(img))
```

**重点观察**：

1. 腐蚀之后，白色大矩形缩小了吗？
2. 膨胀之后，大矩形与噪点变大了吗？
3. 开运算是否去掉孤立白点？
4. 闭运算是否填补大矩形内部小孔？
5. 比较不同核大小时，缺陷面积及边缘发生怎样的变化？

### 已有灰度图片的标准入口

```python
import cv2

img = cv2.imread('input.png', cv2.IMREAD_GRAYSCALE)
if img is None:
    raise FileNotFoundError('input.png')

# 先分割，得到白色为目标的二值图
_, binary = cv2.threshold(img, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3))

# 只在有依据时使用以下清理步骤
mask = cv2.morphologyEx(binary, cv2.MORPH_OPEN, kernel)
mask = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, kernel)

# 可接下一步：连通域测量
num_labels, labels, stats, centroids = cv2.connectedComponentsWithStats(mask, connectivity=8)
for i in range(1, num_labels):  # 跳过背景 0
    x, y, w, h, area = stats[i]
    print(f'defect #{i}: x={x}, y={y}, width={w}, height={h}, area={area}')
```

> ⚠️ 注意：`THRESH_BINARY + OTSU` 只把**高灰度区域**作为白色前景，未必对应缺陷。如果目标比背景暗，可考虑 `THRESH_BINARY_INV + OTSU`；对于背景不均匀的图像，Otsu 也未必合适。**不要把上述连续开闭视为所有图片的固定配方**。

## 六、工业缺陷检测里怎么选择？

以半导体光学检测或一般工业表面检测为例，先明确**待检缺陷在二值图中是否为白色**。

| 观察到的问题 | 可优先尝试 | 评估时特别注意 |
|---|---|---|
| 大量孤立亮点，确认它们是噪声 | 开运算 | 小型真实亮缺陷也可能被删除 |
| 缺陷区域内部有微小黑孔 | 闭运算 | 不要让大面积不同区域被错误合并 |
| 两条本应连续的亮线之间有窄缝 | 小核闭运算或定向膨胀 | 连接后长度、宽度及面积不再是原始值 |
| 两个白色颗粒之间存在细连接 | 小核腐蚀 | 颗粒边界与面积会缩小 |
| 需检出极细划痕或极小缺陷 | **先保留原掩码并做对比实验** | 过强的开运算可能直接抹除目标 |
| 黑色缺陷位于亮背景 | 先确定反色策略 | 反色后才可套用白色前景的操作逻辑 |

**工程判断标准**：不仅看“图片是否干净”，还要看召回率、误检数、缺陷面积误差、目标连接关系是否被改变。用于精密测量时，形态学结果可能仅适于候选区域提取，最终尺寸要回到原始图像/高精度边缘上计算。

## 七、拓展：另外三个常见形态学操作

> 以下是 1.6 四个必学操作以外的扩展知识。

### 7.1 形态学梯度（Morphological Gradient）

$$
G = (I\oplus B) - (I\ominus B)
$$

用于提取边缘附近的区域，**不是** Sobel/Canny 那样的梯度求导。

```python
gradient = cv2.morphologyEx(img, cv2.MORPH_GRADIENT, kernel)
```

### 7.2 顶帽（Top-hat）

$$
T = I - (I\circ B)
$$

可突出比结构元素尺度更小的**局部亮结构**，常用于不均匀背景下的亮小点增强。

```python
tophat = cv2.morphologyEx(img, cv2.MORPH_TOPHAT, kernel)
```

### 7.3 黑帽（Black-hat）

$$
H = (I\bullet B) - I
$$

可突出**局部暗结构**，例如明亮背景上的细暗线、暗孔。

```python
blackhat = cv2.morphologyEx(img, cv2.MORPH_BLACKHAT, kernel)
```

> 顶帽/黑帽的表现强烈依赖结构元素大小及灰度背景，不保证对所有划痕或缺陷都有效。

## 八、常见面试题与简答

**Q1：腐蚀和膨胀的核心区别是什么？**  
A：对亮前景而言，腐蚀要求结构元素范围内前景“全部成立”，使区域收缩；膨胀只需有前景参与，就可扩大区域。对平坦灰度图，可分别理解为局部最小值和局部最大值。

**Q2：开运算和闭运算为什么顺序不能反过来？**  
A：开运算是腐蚀后膨胀，目的是优先消除小亮结构；闭运算是膨胀后腐蚀，目的是优先填补小暗空隙。顺序变化会改变处理的形态目标。

**Q3：开运算会不会删除真实缺陷？**  
A：会。只要真实缺陷的几何尺度、厚度或形状相对于结构元素太小，也可能被删除。要依据最小可检缺陷尺寸选核并验证召回率。

**Q4：形态学能替代阈值分割吗？**  
A：不能直接等价替代。阈值分割确定前景/背景，形态学主要调整这些区域的几何结构；形态学也能直接作用于灰度图。

**Q5：做面积测量时能不能直接用膨胀后的像素数？**  
A：不能当作原始面积。膨胀改变了边界和面积；若需物理面积，还需要像素标定，并评估处理带来的系统误差。

**Q6：如何选 3×3、5×5 还是 7×7？**  
A：根据噪点尺寸、缺陷最小尺度及形状，用验证集比较噪点清除率、缺陷召回率和形状误差，不能只凭画面效果。
